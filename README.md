Expense Tracker Mobile App



A simple and clean Expense Tracker mobile application built with Flutter and Firebase.



Features



\- Add new expenses

\- Edit existing expenses

\- Delete expenses

\- Select expense category

\- Select expense date

\- Add optional notes/descriptions

\- Store expenses using Firebase

\- Display total expenses for the current month

\- View expense history

\- Filter expenses by category

\- Filter expenses by date

\- Form validation

\- Loading state

\- Empty state

\- Error handling

\- Clean and responsive user interface



Expense Details



Each expense contains:



\- Title

\- Amount

\- Category

\- Date

\- Optional Note/Description



Technologies Used



\- Flutter

\- Dart

\- Firebase

\- Cloud Firestore

\- Android Studio

\- Git \& GitHub



Project Setup



1\. Clone the repository



git clone https://github.com/Irushee2003/expense\_tracker.git



2\. Open the project



Open the project using Android Studio.



3\. Install dependencies



flutter pub get



4\. Firebase Setup



Connect the project to Firebase and configure Firebase for the Android application.



Add the required Firebase configuration files to the project.



5\. Run the application



Connect an Android device or start an Android emulator and run:



flutter run
